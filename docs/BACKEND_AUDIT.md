## 2. Service Inventory (Current State)
1. **Frontend Client**: React 18 SPA bundled with Vite, styled with custom CSS (`neo-brutalist` elements). Direct connections to Firebase Firestore, Firebase Auth, Firebase Storage, Wandbox, and backend WebSockets.
2. **Node.js Backend Monolith (`backend/server.js`)**: 1005 lines of mixed concerns: Express HTTP server, WebSocket servers (`/yjs`, `/comms`, `/api/terminal`), child process spawning, local file uploads, and in-memory chat arrays.
3. **Stand-Alone Yjs Server (`server.js`)**: 20 lines running simple `y-websocket` on port 1234, disconnected from the main application.
4. **PostgreSQL Database**: Configured in `backend/server.js` with 4 basic tables (`users`, `annotations`, `rooms`, `yjs_documents`). Lacks relations, multi-tenancy keys, and foreign key constraints.
5. **SQLite Database (`backend/database.sqlite`)**: Seeded by `seed-accounts.js` but completely orphaned by the running server.
